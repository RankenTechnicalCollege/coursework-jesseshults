Modifying Images

Using descriptive file names for image files is important because it improves organization, makes images easier to search for, and ensures consistency when working on group projects or large websites.

I used Microsoft Paint to change the image size.

The original size of the image was 2121 pixels wide by 1414 pixels high.

Image Before Compression

The online compressor I used to reduce the image file size was compressor.io. The original file size for this image was 883 KB; after compression, the new file size is 45 KB.

Image After Compression

After compression, the image appears slightly less sharp and some details are softer, but the overall quality is still good for use on a webpage.
